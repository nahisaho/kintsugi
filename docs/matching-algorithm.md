# 破片組み立てアルゴリズム詳細解説

本書は、3Dスキャンした土器破片群をどのようなアルゴリズムで解析・グルーピング・
接合し、最終的な組み立て結果を生成しているかを解説します。実装の正本は
`src/core/` 配下のソースコードであり、対応する設計根拠は
`.musubix/features/pottery-fragment-reassembly/design.md` の各 `DES-POTTERY-*`
（設計コンポーネントID）に記載されています。本書はそれらを平易にまとめた
補足資料です。

## 全体パイプライン

```
① スキャンデータのインポート
        ↓
② 器物クラスタリング（どの破片がどの器物に属するか）
        ↓
③ 破断面接合候補の推定（破片ペアごとの一致度スコア・推定姿勢）
        ↓
④ 組み立て（完全自動 / 半自動 / 手動微調整、矛盾検出を伴う）
        ↓
⑤ 欠損部分推定（任意）・レポート・メッシュ出力
```

以下、②〜④の中核アルゴリズムを順に解説します。

---

## ① スキャンデータのインポート

- 対応形式: STL、頂点色・テクスチャ座標付きOBJ（関連MTL含む）、法線・RGB色を
  含みうる生の点群（XYZ/PCD相当）。
- 単位は既定でミリメートル（mm）として扱い、利用者が明示指定した場合はその
  単位に換算する。
- 1ファイルの読込失敗（破損・非対応形式・必須ジオメトリ欠如）は当該ファイル
  のみをエラーとして報告し、他の読込済み破片には一切影響しない。

実装: `src/core/scan_importer.cpp`

---

## ② 器物クラスタリング（同一器物由来の判定）

複数の器物に由来する破片が混在している可能性があるため、まず「どの破片が
どの器物候補に属するか」を推定します。

### 特徴量

各破片について、以下2種類の特徴量を抽出します（`fragment_clustering.cpp`）。

1. **肉厚（thickness）**: 破片の頂点座標のバウンディングボックスにおける
   3軸のうち最小の辺の長さ。土器は成形時の肉厚が器物ごとにある程度均一な
   ため、同一器物の破片同士は肉厚が近い値になりやすいという性質を利用する。
2. **頂点色の平均（RGB）**: 頂点色情報がある場合、その平均色。彩色・釉薬の
   色合いが器物ごとに異なることを利用する。

### 所属信頼度の算出

破片ペア (A, B) について、正規化した肉厚差と色差から「所属信頼度」
（0〜100、値が大きいほど同一器物由来の可能性が高い）を算出します。

```
thicknessDist = min(|thicknessA - thicknessB| / 20mm, 1.0)

色情報が両方にある場合:
  colorDist = min(RGBユークリッド距離 / 441.67, 1.0)   # 441.67 = √(255²×3)
  combinedDist = 0.5 × thicknessDist + 0.5 × colorDist
色情報がない場合:
  combinedDist = thicknessDist

confidence = (1.0 - combinedDist) × 100
```

### グルーピング（Union-Find + 反復的信頼度精査）

1. 全破片ペアについて所属信頼度を計算し、**70以上**のペアをUnion-Find
   （互いに素集合）で結合し、初期グループを作る。
2. 各グループについて、メンバー全員の「グループ内平均信頼度」を再計算し、
   平均信頼度が70未満のメンバーをグループから除外する処理を、安定する
   （全メンバーが70以上になる、またはメンバー数が1以下になる）まで反復する。
   - これは、A-B間・B-C間はそれぞれ70以上でも、推移的にA-Cまで同一グループ
     に含めてよいとは限らない（Union-Findの推移的併合だけでは過剰結合が
     起こりうる）ことへの対処です。
3. 最終的にメンバー数が2以上のグループを「器物候補（VesselCluster）」とし、
   1未満（1個または反復で全滅）のグループの破片は「未分類破片
   （unclassified）」として区別します。

採用閾値70は固定値であり、同一入力に対して常に同一出力を返す決定的な処理
です（乱数・非決定要素なし）。

実装: `src/core/fragment_clustering.cpp`

## ③ 破断面接合候補の推定

器物候補内の破片ペアごとに、「本当に接合できそうか」を判定し、接合姿勢の
候補を1件算出します。中核は次の3ステップです（`fragment_matching.cpp`）。

### ステップ1: 破断面点群の抽出（局所曲率によるセグメンテーション）

土器の表面（釉薬面・成形面）は比較的滑らかですが、破断面は不規則な凹凸を
持ちます。この性質を使って、各破片の点群から「破断面らしい点」だけを抽出
します。

1. 各点について、k近傍点（既定8点）の座標からPCA（主成分分析）による
   共分散行列を求め、その最小固有値の全固有値和に対する比率
   `λmin / (λ0+λ1+λ2)` を「局所曲率（表面変動量）」とする。
   - 平滑な面ではこの値は0に近く、不規則な凹凸がある破断面では大きくなる。
2. 全点の局所曲率の平均・標準偏差を求め、「平均＋標準偏差」を超える点を
   破断面点として抽出する。
3. 抽出点数が少なすぎる（既定4点未満）場合は、ICPの退化を避けるため全点を
   そのまま用いる（フォールバック）。

### ステップ2: ICP（Iterative Closest Point）による姿勢推定と形状スコア

抽出した破断面点群同士を、PCLの `IterativeClosestPoint` で位置合わせします。

1. 両破片の破断面点群の重心差を初期並進として与える。
2. 最大200回の反復でICPを実行し、収束判定（`hasConverged()`）とフィット
   ネス残差（RMS）を取得する。
3. 残差を「両破片の外接直径の平均」でスケール正規化し、正規化スケール
   （既定0.05）に対する比率が1.0以上なら残差寄与を頭打ちにする。
4. 形状一致度スコア（0〜100）は次の式で求める。

```
normalizedFitness = min(RMS残差 / 外接直径平均 / 0.05, 1.0)
shapeScore = ICPが収束した場合: (1.0 - normalizedFitness) × 100
             ICPが収束しなかった場合: 0（残差の値によらず信頼度0）
```

ICP最終変換行列から並進ベクトルと回転（クォータニオン）を抽出し、これが
接合候補の推定姿勢 `pose` になります。

### ステップ3: 色・模様連続性スコア（任意）

両破片に頂点色情報がある場合のみ、破断面点群に対応する頂点色の平均同士の
ユークリッド距離から色連続性スコア（0〜100）を追加で算出します。

```
colorScore = (1.0 - min(RGB距離 / 441.67, 1.0)) × 100
```

破断面近傍の色のみを使う（全体平均は使わない）ことで、器物全体としては
似た色でも破断面付近の色が不連続な誤接合を区別しやすくしています。

### 総合信頼度スコア

```
色情報がある場合: confidence = clamp(0.7 × shapeScore + 0.3 × colorScore, 0, 100)
色情報がない場合: confidence = shapeScore
```

形状一致度を主要項（重み0.7）とし、色・模様連続性を補助項（重み0.3）として
組み合わせます。同一破片ペアにつき候補は1件のみ生成されます。

## ④ 組み立て（AssemblyOrchestrator）

算出済みの接合候補群から、実際に「どの破片をどの姿勢で採用するか」を決定
する処理です。3つのモードを提供します（`assembly_orchestrator.cpp`）。

### 姿勢の伝播と矛盾判定（共通基盤）

- 破片Bを破片A基準の座標系へ接合する場合、Aの現在の（伝播済み）姿勢に
  候補の相対姿勢を合成（クォータニオン積＋回転を考慮した並進合成）して、
  Bの絶対姿勢を求める（`propagatePose`、`src/core/pose_conflict.cpp`）。
- 同じ破片に対して複数経路から異なる姿勢が導かれた場合、次の基準で
  「矛盾」と判定する。
  - 並進差 > **1.0mm**、または
  - 回転差 > **2°**（クォータニオン内積から最短回転角を算出）
- この矛盾判定ロジックは完全自動モードと半自動モードの警告表示の両方から
  同一実装を参照し、判定結果が食い違わないようにしている。

### 完全自動モード（`runFullAuto`）

1. 信頼度70以上の候補のみを対象とする。
2. 信頼度降順（同点の場合は破片ID対の昇順）で安定ソートする。
3. 候補を順番に評価し、既存の採用済み接合と矛盾しなければ採用
   （`AcceptedJoin` として記録）、矛盾すれば却下候補として理由付きで記録する。
4. 全候補を走査後、隙間・重なりを再評価する。

決定的な走査順序（信頼度降順・破片ID昇順のタイブレーク）により、同一入力
からは常に同一の採用結果が得られます。

### 半自動モード

候補一覧を信頼度順・根拠（形状スコア・色スコア・ICP収束有無）付きで提示し、
利用者が個別に「採用」「却下」を選択します。採用時も同じ矛盾判定を経て、
矛盾がある場合は警告のみで採用されません。GUI上では選択中の候補に対応する
2破片をハイライト表示し、選択を解除すると元の表示色に戻ります。

### 手動微調整

ドラッグ操作等で個々の破片の姿勢を直接更新するコマンドを受け付け、
組み立て状態（AssemblyState）に反映したうえで隙間・重なりを再評価します。

### undo/redo

候補の採否・姿勢変更操作はすべて変更履歴として記録され、取り消し・
やり直しが可能です。

## ⑤ 欠損部分推定（任意機能）

組み立て済みの部分が轆轤（ろくろ）成形による回転対称形状であると判定できる
場合にのみ有効化される機能です。回転軸を推定し、その軸まわりの断面
プロファイル曲線を回転させることで、欠損している部分の概形を推定します。
回転対称と判定できない場合、または機能無効時は推定を行いません（実測データ
とは明確に区別できる推定形状レコードとして出力）。

実装: `src/core/missing_part_estimation.cpp`

## まとめ図

```
FragmentMesh[]
   │  (肉厚 + 頂点色 平均) による特徴抽出
   ▼
clusterFragments()
   │  Union-Find + 反復的グループ内平均信頼度チェック（閾値70）
   ▼
{ VesselCluster[] , unclassified: FragmentMesh[] }
   │  各VesselCluster内の全ペアについて…
   ▼
computeJoinCandidates()
   │  ① 局所曲率で破断面点群を抽出
   │  ② 破断面点群同士をICPで位置合わせ → 形状スコア + 推定姿勢
   │  ③ 破断面近傍の色平均差から色連続性スコア（任意）
   │  confidence = 0.7×shapeScore + 0.3×colorScore（色情報なければshapeScoreのみ）
   ▼
JoinCandidate[]  { fragmentIdA, fragmentIdB, pose, confidenceScore, evidence }
   │
   ▼
AssemblyOrchestrator
   │  完全自動: 信頼度降順に矛盾なしの候補のみ貪欲採用
   │  半自動  : 利用者が候補を選択して採否（同じ矛盾判定を使用）
   │  手動    : ドラッグによる姿勢の直接編集
   ▼
AssemblyState（全破片の姿勢・採用済み接合・却下候補・未接合破片）
```

## 参考: 主要な閾値・パラメータ一覧

| パラメータ | 値 | 用途 |
|---|---|---|
| クラスタ所属信頼度の採用閾値 | 70 | 器物候補へのグルーピング（REQ-POTTERY-003） |
| 肉厚差の正規化スケール | 20mm | 器物クラスタリングの特徴量正規化 |
| 破断面抽出の近傍点数 | 8点 | 局所曲率（PCA）計算 |
| 破断面点数の下限 | 4点 | 抽出結果が少なすぎる場合のフォールバック条件 |
| ICP最大反復回数 | 200 | 破断面点群の位置合わせ |
| フィットネス残差の正規化スケール | 0.05 | 形状一致度スコアの正規化 |
| 形状スコアの重み | 0.7 | 総合信頼度スコアの合成 |
| 色スコアの重み | 0.3 | 総合信頼度スコアの合成（色情報がある場合のみ） |
| 接合候補の採用閾値（完全自動） | 70 | 完全自動モードでの貪欲採用対象 |
| 姿勢矛盾判定: 並進差 | 1.0mm | これを超えると矛盾と判定 |
| 姿勢矛盾判定: 回転差 | 2° | これを超えると矛盾と判定 |

いずれのパラメータも実装上は固定値（コード中の定数）であり、乱数や
非決定的な処理を含まないため、同一入力に対して常に同一の出力を返します。
