# ADR-0003: 破断面接合候補推定アルゴリズムの選定

## Context / 背景
REQ-POTTERY-004/005/018/025/028は、破断面形状の一致度（および利用可能な場合は
色・模様の連続性）に基づき破片対ごとに単一の接合候補姿勢と信頼度スコア（0〜100）を
算出し、固定ベンチマークPFR-BENCH-001において適合率90%以上・再現率85%以上、かつ
正解接合ペアの信頼度中央値が誤接合ペアの中央値を上回ることを要求する。オフライン・
Windows単体実行（REQ-POTTERY-016/017）かつ再現可能なベンチマーク測定（REQ-POTTERY-
019）が前提のため、外部学習済みモデルの追加取得や実行時ネットワーク依存を伴う手法は
採用できない。

## Decision / 決定
古典的な多段階幾何レジストレーションパイプラインを採用する：
1. 破断面境界曲線からの特徴量（局所曲率・法線分布等）による粗位置合わせ候補生成。
2. 破断面点群に対するICP（Iterative Closest Point）による姿勢の精密化。
3. ICP後の表面距離適合度（フィッティング残差）を主要項とし、破片に色・模様情報が
   付与されている場合は色・模様連続性スコアを加算した重み付け線形結合により、
   0〜100の信頼度スコアを算出する。
本パイプラインは決定的（同一入力に対し同一出力）であり、学習済みモデルの配布・
バージョン管理を必要としない。

## Rejected Alternatives / 却下した代替案
- **深層学習ベースの形状マッチングモデル**: 大量のラベル付き破片破断面データセットに
  よる事前学習が必要であり、本システムの対象（多様な土器・多様な破損状態）に対する
  汎化性能を検証する手段が現時点でない。また学習済みモデルの配布・更新はオフライン
  要件（REQ-POTTERY-016）と衝突し、判定根拠の説明可能性（REQ-POTTERY-007の根拠提示
  要件）も低下する。
- **形状のみによる単純点群距離（最近傍距離平均）のみでの信頼度算出**: 色・模様情報
  （REQ-POTTERY-005）を評価に組み込めず、模様が識別的な破片群での誤接合を抑制でき
  ない。

## Consequences / 結果
古典的パイプラインはハードウェア・入力データが固定されていれば再現性が高く、
PFR-BENCH-001によるベンチマーク測定・回帰検証が可能である。一方、極めて摩耗・
風化した破断面など特徴量が乏しいケースでは信頼度が伸び悩む可能性があり、将来的な
アルゴリズム改善（特徴量追加等）は本ADRの前提を変えずに信頼度算出ステップのみを
差し替える形で行う。
