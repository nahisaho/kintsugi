# デモ用スキャンデータ

3Dスキャナーで取得した破片データを模した、デモ・動作確認用の合成点群です。

## 内容

高さ120mm・最大半径50mm程度の壺（土器）を模した曲面 ―
底部(半径小)→胴部(最大膨らみ)→肩部(すぼまり)→首部(最も細い)→
口縁(わずかに開く) というシルエットの表面を、100個の不定形な破片に
分割したメッシュを用意しています（`pottery_fragment_001.obj`〜
`pottery_fragment_100.obj` のうち、実際の出土状況を模して一部(既定で約15%)
を欠損(紛失)扱いとして間引いた85個、および壺本体とは接合しない
「マッチしない破片」(別の器・がれき由来を想定、既定5個、
`pottery_fragment_101.obj`〜`pottery_fragment_105.obj`)を加えた
計90個 と、対応する `.mtl`）。単純な円柱形状
ではなく、実際の壺に近いプロファイル曲線を用いています。角度・高さ空間上に
ジッターを与えた種点によるVoronoi分割で破片形状を決めているため、
実際の破損片に近い不定形・不均一なサイズ（1破片あたり約100〜400頂点、
平均約250頂点）になっています。各破片は隣接する破片と自然な境界で
接しており、アプリの「スキャンをインポート」→「クラスタリング実行」→
接合候補の提示、という一連のフローを100破片規模で試すのに使えます。
一部番号（欠損扱いにした破片）のファイルは存在しないため、復元後の
壺の表面には数か所の欠損(空白)が残ります。

各破片は面(三角形)情報を持つ Wavefront OBJ 形式で、対応する
`.mtl` ファイル(`mtllib`/`usemtl`で参照)で破片ごとの色を定義しています:

```
mtllib pottery_fragment_NNN.mtl
v x y z          # 頂点
vn nx ny nz      # 法線
usemtl fragmentN
f a//a b//b c//c # 三角形面（頂点・法線とも同一インデックス）
```

- 位置・法線: 壺のプロファイル曲面に沿った法線（断面の半径方向成分に、
  プロファイルの高さ方向の傾き(dr/dh)による表面の傾斜を加味）に、
  実スキャンらしいノイズ(σ=0.3mm)を付加。
- 面: 角度・高さのグリッド上で隣接する4頂点が同一破片に属する場合のみ
  2枚の三角形として面を張る（破片境界をまたぐセルには面を張らないため、
  破片同士の境界は不揃いなまま残り、実際の破損片の見た目に近くなる）。
  面情報を持つため、3Dビューア上で各破片のメッシュエッジ（輪郭線）が
  表示される。
- 色: 破片ごとに近似的なテラコッタ色パレット(8色)を巡回で割り当て
  （`.mtl`の`Kd`として定義。破片識別を視覚的に確認しやすくするため）。
- マッチしない破片(`_101`〜`_105`): 壺のプロファイルとは無関係な局所曲率
  (放物面近似、曲率半径をランダムに変えたほぼ平坦〜強い湾曲の小片)を、
  壺本体から離れた位置・向きにランダム配置したもの。グレー系の別配色
  (テラコッタ色パレットとは別)にしており、クラスタリング・接合候補提示が
  「接合先の存在しない破片」を無理に接合しようとしないことを確認できる。

## 使い方

1. アプリを起動し、「1. インポート・クラスタリング」パネルの
   「スキャンをインポート...」ボタンから `demo_data/` 内の
   `pottery_fragment_*.obj` を（複数選択、または全選択で）まとめて
   選択します（対応する`.mtl`は同じフォルダに置いたままにしてください）。
2. 「クラスタリング実行」を押すと100破片が1クラスタとしてまとめられます。
3. 以降、接合候補の提示・採用・手動微調整などの機能を試せます。

## 再生成方法

このデータは `scripts/generate_demo_scans.py`（同梱）で再生成できます:

```bash
python3 scripts/generate_demo_scans.py                 # 100破片(デフォルト、約15%欠損+非マッチ5個)
python3 scripts/generate_demo_scans.py --num-fragments 4  # 破片数を変更する場合
python3 scripts/generate_demo_scans.py --missing-ratio 0  # 欠損なし(全破片を出力)
python3 scripts/generate_demo_scans.py --unrelated-count 0  # マッチしない破片を含めない
```
