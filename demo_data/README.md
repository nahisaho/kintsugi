# デモ用スキャンデータ

3Dスキャナーで取得した破片データを模した、デモ・動作確認用の合成点群です。

## 内容

高さ120mm・半径50mm程度の壺（テーパー付き円柱形状）を、全周4分割した
破片として想定した点群を4ファイル用意しています。各破片は隣接する破片と
角度方向で接する境界を持ち、アプリの「スキャンをインポート」→
「クラスタリング実行」→ 接合候補の提示、という一連のフローを試すのに
使えます。

| ファイル | 角度範囲 | 点数 |
|---|---|---|
| `pottery_fragment_1.pcd` | 0°〜95° | 2400 |
| `pottery_fragment_2.pcd` | 95°〜185° | 2400 |
| `pottery_fragment_3.pcd` | 185°〜270° | 2400 |
| `pottery_fragment_4.pcd` | 270°〜360° | 2400 |

各点は以下のフィールドを持つ PCD (ASCII, v0.7) 形式です:

```
x y z normal_x normal_y normal_z rgb
```

- 位置・法線: 円柱表面の外向き法線に、実スキャンらしいノイズ(σ=0.3mm)を付加。
- 色: 破片ごとに近似的なテラコッタ色を割り当て（破片識別を視覚的に確認しやすくするため）。

## 使い方

1. アプリを起動し、「1. インポート・クラスタリング」パネルの
   「スキャンをインポート...」ボタンから `demo_data/` 内の4ファイルを
   まとめて選択します。
2. 「クラスタリング実行」を押すと4破片が1クラスタとしてまとめられます。
3. 以降、接合候補の提示・採用・手動微調整などの機能を試せます。

## 再生成方法

このデータは `scripts/generate_demo_scans.py`（同梱）で再生成できます:

```bash
python3 scripts/generate_demo_scans.py
```
