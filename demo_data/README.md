# デモ用スキャンデータ

3Dスキャナーで取得した破片データを模した、デモ・動作確認用の合成点群です。

## 内容

高さ120mm・半径50mm程度の壺（テーパー付き円柱形状）の表面を、100個の
不定形な破片に分割した点群を用意しています（`pottery_fragment_001.pcd`
〜`pottery_fragment_100.pcd`）。単純な角度スライスではなく、角度・高さ
空間上にジッターを与えた種点によるVoronoi分割で破片形状を決めているため、
実際の破損片に近い不定形・不均一なサイズ（1破片あたり約100〜400点、
平均約250点）になっています。各破片は隣接する破片と自然な境界で接して
おり、アプリの「スキャンをインポート」→「クラスタリング実行」→接合候補
の提示、という一連のフローを100破片規模で試すのに使えます。

各点は以下のフィールドを持つ PCD (ASCII, v0.7) 形式です:

```
x y z normal_x normal_y normal_z rgb
```

- 位置・法線: 円柱表面の外向き法線に、実スキャンらしいノイズ(σ=0.3mm)を付加。
- 色: 破片ごとに近似的なテラコッタ色パレット(8色)を巡回で割り当て
  （破片識別を視覚的に確認しやすくするため）。

## 使い方

1. アプリを起動し、「1. インポート・クラスタリング」パネルの
   「スキャンをインポート...」ボタンから `demo_data/` 内の
   `pottery_fragment_*.pcd` を（複数選択、または全選択で）まとめて
   選択します。
2. 「クラスタリング実行」を押すと100破片が1クラスタとしてまとめられます。
3. 以降、接合候補の提示・採用・手動微調整などの機能を試せます。

## 再生成方法

このデータは `scripts/generate_demo_scans.py`（同梱）で再生成できます:

```bash
python3 scripts/generate_demo_scans.py                 # 100破片(デフォルト)
python3 scripts/generate_demo_scans.py --num-fragments 4  # 破片数を変更する場合
```
